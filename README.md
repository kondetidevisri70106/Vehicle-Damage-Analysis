# Multi-View Vehicle Damage Analysis with Hidden Damage Risk Prediction

An intelligent vehicle damage assessment system using Deep Learning, Computer Vision, and IoT.

## Features
- Multi-view image upload (front, rear, left, right, close-up)
- YOLOv8-based damage detection (or heuristic fallback)
- Severity estimation (minor / moderate / severe)
- IoT sensor fusion (accelerometer, gyroscope, GPS)
- Hidden damage risk prediction with inspection recommendation
- Repair action recommendation (repair / repaint / replace)
- Repair cost range estimation (INR)
- PDF + JSON report generation
